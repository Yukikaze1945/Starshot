# Starshot Fork 2.6.0-preview.8

Windows x64 预览版，源码与安装包继续在同一个公开仓库发布。

## 本次更新

- 区域截图改用紧凑主工具栏、工具分组菜单和按需参数栏；轻量 GDI 与标准/HDR 模式共享动作与布局规则，保留现有工具及快捷键。
- 工具栏支持选区锚定、DPI/显示器边界定位和窄屏收纳；改进菜单事件穿透、显式颜色/线宽选择及 Esc 的逐层关闭行为。
- 在「更多」中加入 HDR 亮度分析仪：Cursor、Min、Max、Avg、P99、SDR White 参考、可展开波形及可选热力图。
- 亮度分析读取原始 FP16 scRGB，按 `max(0, (0.2126R + 0.7152G + 0.0722B) × 80)` 计算信号亮度；普通 SDR 和轻量 GDI 禁用绝对 nits 分析。热力图不写入保存图片或剪贴板。
- 增加默认关闭的生命周期/性能诊断与独立测试，覆盖取消、重开、异常、选区变化、任务收尾和临时资源释放；正式运行不加入强制 GC。

包含此前已合入源码的轻量/标准/高质量 HDR/单帧 HDR 视频模式、StarshotPerceptual SDR 输出和 PP-OCRv6 Tiny 默认引擎及 Small 可选 DLC。

## 验证与已知限制

- Debug/Release 构建、数学与布局测试、轻量模式交互测试、真实隐藏 XAML 回归通过；WebUI 消息桥与文本格式测试通过。
- 两个独立 Release 隐藏窗口进程各验证 15 轮 4K 合成 FP16 分析；另有纯 CPU 控制实验。诊断 GC 后，跟踪的大型缓冲区及相关面板/任务弱引用全部失效，未发现每轮保留一份缓存的引用泄漏。Private Memory 可因 GC 时机和 CLR 堆保留而暂时升高。
- 一组测得单次 readback 167ms 尖峰，后续 15 轮未复现；尚未确定来源。短期合成测试不证明长期零增长或所有显卡/驱动环境均无卡顿。
- 分析数值是 scRGB 内容信号估计，不是显示器实际发光测量；8K 大选区抽样可能漏掉细小峰值。

## 下载与升级

- `Starshot-2.6.0-preview.8-setup-x64.exe`：离线安装包，内置 Microsoft WebView2 Runtime，仅在缺失时安装。
- `Starshot-2.6.0-preview.8-win-x64.zip`：便携包，需要已安装 WebView2 Runtime。
- `SHA256SUMS.txt`：安装包与便携包校验值。

覆盖安装保留现有配置和模型数据。安装版继续使用当前每用户 Starshot Fork 目录，便携版从根目录 `Starshot.exe` 启动。软件可检查本仓库更新，预览版需要启用接收预览更新。

安装包目前未配置 Starshot 产品签名证书。
