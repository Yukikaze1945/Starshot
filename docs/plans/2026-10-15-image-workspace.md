# Starshot 图像工作区

范围：Windows Starshot；保留现有未提交修改。用户确认相册指 Windows 截图库，不改 Android 工程。不使用子代理，不安装、不推送、不发布；通过 Run-Starshot.cmd 构建 Debug 源码版。

## 实施顺序与验收

1. **P0 UHDR 完整解码**：libultrahdr 原生解码为线性 FP16，处理 stride、输出色域与 SDR 参考白，保留普通 JPEG 回退。用现有 P3 gainmap 合成样本验证高光、色彩和生命周期。
2. **P0 双图对比与内置图库查看**：图库直接进入图像工作区，缩放/平移/前后导航；选择两图进行同步缩放、并排/分割对比。HDR 的原生查看保留；网页显示明确标记 SDR 预览，不冒充 HDR。
3. **P1 色域与亮度分析**：按需分析原始 FP16 scRGB，显示 sRGB/P3/2020 区域占比、xy 分布、亮度统计/波形/热图、像素读数；资格判断、近似标记、取消和缓存清理可验证。
4. **模型管理库与离线翻译**：统一展示内置 Tiny、Small、Index-Translate-2B Q5_K_M（默认下载规格）及抠图模型。官方/明确来源、固定版本、SHA-256、进度/取消/校验/原子安装/删除、应用数据目录。推理运行时随程序固定部署，模型下载不执行任意 DLL。离线翻译 lazy-load，并复用现有格式与翻译入口。
5. **原位翻译**：按 OCR 行框编辑翻译覆盖层，使用现有 SDR OCR 输入与翻译服务；覆盖层默认不改原图，显式导出才写入。
6. **统一蒙版与抠图**：区域截图工具栏增加抠图入口，两种截图模式行为一致，轻量路径保持纯 CPU。多边形逐点 Ctrl+Z/重做、自由套索、魔棒、模型分割共享蒙版、历史与草稿。图库同样可编辑。透明导出 PNG，其他格式不隐式丢 alpha。
7. **验证**：数学/蒙版/下载失败与取消/离线模型推理/前端交互/现有 CPU 截图回归；隐藏合成输入，不操作桌面截图；临时图像 finally 清理。完整 Debug 源码启动脚本构建通过。不能完成的硬件验证如实列出。

## 实现边界

- 新工作区使用已校验文件 ID 和有限消息桥，不允许前端任意读取文件系统。
- CPU/GDI 轻量截图不因为抠图或分析初始化 WGC/Win2D；把 SDR 字节交给 CPU 编辑会话。
- 原始图像与显示预览分离；不修改 HDR 编码算法、UHDR base/gainmap 或 WGC context。
- 图库工作区、分析、蒙版、模型下载及推理各自可取消；关闭/换图时释放所属资源，历史有上限。
- 不把启发式魔棒称为 AI；智能抠图使用实际分割模型。模型不可用时明确提示，不静默装作成功。
